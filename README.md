## 📖 About This Repository

This repository contains my **React learning journey**, with hands-on exercises and small applications developed while learning the core concepts of React.

The projects progress from **basic component development and props** to **event handling, forms, conditional rendering, and state management with `useState`**.

Rather than keeping isolated code snippets, I organized the exercises into practical projects to understand how React applications are structured and how individual concepts work together.

# 💻 Running the Projects

Each project is an independent Vite application.

### 1️⃣ Navigate to a project

```bash
cd Basic-React/basic-React-App
```

or:

```bash
cd React-State/react-states
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Start the development server

```bash
npm run dev
```

Then open the local URL provided by Vite, usually:

```text
http://localhost:5173
```
